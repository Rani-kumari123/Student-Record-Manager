# Student Record Manager

A beginner-friendly C++ project for managing student records using data structures, searching, and sorting.

## 📌 Project Overview

Student Record Manager is a console-based C++ application designed to manage student records efficiently.
Each student record contains:

- Roll Number
- Name
- Marks

## ✨ Features

- Add new student
- Display all students
- Search for a student
- Delete a student
- Sort student records
- Linear Search
- Binary Search
- Menu-based interface

## 🛠️ Technologies Used

- C++
- Arrays
- Data Structures
- Searching Algorithms
- Sorting Algorithms

## 🔍 Searching Algorithms

### Linear Search
Checks student records one by one to find the required student.

**Time Complexity:** O(n)

### Binary Search
Searches for a student in a sorted list by repeatedly dividing the search range.

**Time Complexity:** O(log n)

## 🔃 Sorting

Sorting is used to arrange student records in a particular order.

**Time Complexity:** O(n²) for basic sorting algorithms used in this project.

## ⏱️ Time Complexity

| Operation | Time Complexity |
|---|---|
| Insertion | O(1) |
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Sorting | O(n²) |
| Deletion | O(n) |

## ▶️ How to Run

1. Download or clone this repository.
2. Open `student_record.cpp` in VS Code or any C++ compiler.
3. Compile the program.
4. Run the program.
5. Select an option from the menu.
